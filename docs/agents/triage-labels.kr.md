# 트리아지 라벨

스킬은 다섯 가지 표준 트리아지 역할을 기준으로 기술됩니다. 이 파일은 해당 역할을 이 저장소의 이슈 트래커에서 사용하는 실제 라벨 문자열에 매핑합니다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨 | 의미                                          |
| ------------------------ | ------------------ | --------------------------------------------- |
| `needs-triage`           | `needs-triage`     | 유지 관리자가 이 이슈를 평가해야 함           |
| `needs-info`             | `needs-info`       | 보고자의 추가 정보를 기다리는 중              |
| `ready-for-agent`        | `ready-for-agent`  | 완전히 명세되었으며, AFK 에이전트가 처리 가능 |
| `ready-for-human`        | `ready-for-human`  | 사람의 구현이 필요함                          |
| `wontfix`                | `wontfix`          | 조치하지 않음                                 |

스킬이 역할을 언급하는 경우(예: "AFK 준비 완료 트리아지 라벨을 적용하라"), 이 표에서 해당하는 라벨 문자열을 사용하십시오.

상태를 선택하기 전에 모든 이슈를 [`SCOPE.md`](../../SCOPE.md)에 따라 판단하십시오. 거절된 이슈는 "not planned"로 종료됩니다.
