새로운 에이전트가 작업을 이어갈 수 있도록 현재 대화를 요약하는 인계 문서를 작성하십시오. 현재 작업 공간이 아니라 사용자 OS의 임시 디렉터리(`$TMPDIR`, 없으면 `/tmp`, Windows에서는 `%TEMP%`)에 저장하십시오.

다음 에이전트가 Skill 도구로 호출해야 할 스킬을 명시하는 "제안 스킬(suggested skills)" 섹션을 문서에 포함하십시오.

다른 산출물(명세, 계획, ADR, 이슈, 커밋, diff)에 이미 담긴 내용을 중복하지 마십시오. 대신 경로나 URL로 참조하십시오.

API 키, 비밀번호, 개인 식별 정보와 같은 민감한 정보는 모두 삭제하십시오.

사용자가 인수를 전달한 경우, 이를 다음 세션이 집중할 내용에 대한 설명으로 간주하고 그에 맞추어 문서를 작성하십시오.
