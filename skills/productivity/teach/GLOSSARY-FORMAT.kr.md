# GLOSSARY.md 형식

`GLOSSARY.md`는 이 교육 작업 공간의 표준 언어입니다. 모든 설명 자료, 연습 문제, 학습 기록은 이 용어를 따라야 합니다. 이를 구축하는 것 자체가 학습의 일부입니다. 개념을 간결한 정의로 압축하는 것은 사용자가 그 개념을 이해하고 있다는 증거입니다.

## 구조

```md
# {주제} 용어집

{이 용어집이 다루는 주제에 대한 한두 문장의 설명.}

## 용어

**근비대(Hypertrophy)**:
반복적인 훈련 세션에 걸친 기계적 장력과 대사적 스트레스에 의해 유발되는 근육 성장.
_사용하지 말 것_: 벌크업, 몸 키우기

**점진적 과부하(Progressive overload)**:
부하, 볼륨, 또는 강도를 통해 시간이 지남에 따라 근육에 가해지는 요구를 체계적으로 증가시키는 것.
_사용하지 말 것_: 더 세게 밀어붙이기, 레벨 업

**RPE (Rate of Perceived Exertion, 자각적 운동 강도)**:
한 세트가 얼마나 힘들었는지에 대한 1~10점의 자기 평가로, 10은 실패 지점이며 8은 두 번의 반복 여력이 남았음을 의미함.
_사용하지 말 것_: 노력 점수, 강도 등급
```

## 규칙

- **사용자가 이해한 경우에만 용어를 추가하십시오.** 용어집은 압축된 지식의 기록이지, 사용자가 배우기 위해 읽는 사전이 아닙니다. 사용자가 방금 개념을 처음 접했다면, 그 개념을 올바르게 사용할 수 있을 때까지 기다린 후 이곳에 올리십시오.
- **분명한 입장을 취하십시오.** 같은 개념에 대해 여러 단어가 존재하는 경우, 가장 좋은 것을 선택하고 나머지는 사용하지 말아야 할 별칭으로 나열하십시오. 이것이 언어가 압축되는 방식입니다.
- **정의를 간결하게 유지하십시오.** 한두 문장입니다. 용어가 무엇을 하는지, 또는 어떻게 하는지가 아니라 용어가 무엇인지를 정의하십시오.
- **정의 안에서도 용어집의 용어를 사용하십시오.** 용어가 용어집에 등록되면, 다른 정의 내부를 포함하여 모든 곳에서 그 용어를 우선 사용하십시오. 이렇게 하면 나중에 복잡한 용어를 더 쉽게 파악할 수 있습니다.
- 자연스러운 묶음이 생기면 **하위 제목 아래로 그룹화하십시오**(예: `## 해부학`, `## 프로그래밍`). 용어들이 일관성이 있다면 평면 목록도 괜찮습니다.
- **모호성을 명시적으로 표시하십시오.** 어떤 용어가 더 넓은 분야에서 느슨하게 사용되는 경우, 해결 방식을 기록하십시오. "이 작업 공간에서 '세트'는 항상 본 세트를 의미하며, 워밍업은 별도로 추적합니다."
- **이해가 깊어지면 수정하십시오.** 사용자가 첫 주에 작성한 정의는 여섯째 주에는 틀린 것일 수 있습니다. 해당 위치에서 업데이트하고, 낡은 항목을 남겨 두지 마십시오.
