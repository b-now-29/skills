새로운 에이전트가 작업을 이어갈 수 있도록 현재 대화의 인계 요약을 작성하십시오. 이를 사용자 OS의 임시 디렉터리에 저장한 다음, 그것을 프롬프트로 하는 백그라운드 에이전트를 실행하십시오: `claude --bg --name "<descriptive name>" -- "$(cat <summary file>)"`. 파일을 전달하면 셸이 요약 안의 백틱을 실행하거나 `$`를 확장하지 않습니다. 에이전트는 현재 작업 디렉터리에서 시작하며 즉시 반환됩니다. 사용자는 `claude agents`로 이를 관리합니다.

항상 설명적인 이름과 함께 `-n`/`--name`을 전달하십시오(예: `--name "Fix login bug"`). 이 값은 작업 목록, 세션 선택기, 터미널 제목에 표시되는 표시 이름을 설정합니다.

다음 에이전트가 Skill 도구로 호출해야 할 스킬을 명시하는 "제안 스킬(suggested skills)" 섹션을 요약에 포함하십시오.

다른 산출물(명세, 계획, ADR, 이슈, 커밋, diff)에 이미 담긴 내용을 중복하지 마십시오. 대신 경로나 URL로 참조하십시오.

요약은 에이전트의 프롬프트가 되므로, API 키, 비밀번호, 개인 식별 정보와 같은 민감한 정보는 모두 삭제하십시오.

사용자가 인수를 전달한 경우, 이를 다음 세션이 집중할 내용에 대한 설명으로 간주하고 그에 맞추어 요약을 작성하십시오.
