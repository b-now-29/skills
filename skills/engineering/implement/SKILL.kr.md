사용자가 명세나 티켓에서 기술한 작업을 구현하십시오.

사용자가 티켓 참조를 전달하면, 이슈 트래커에서 가져와 시작하기 전에 그 제목을 명시하십시오. 참조가 모호하다면 물어보십시오.

가능한 경우, 사전에 합의된 시임에서 "tdd"로 Skill 도구를 호출하십시오.

타입 검사와 단일 테스트 파일은 정기적으로 실행하고, 전체 테스트 스위트는 마지막에 한 번 실행하십시오.

완료되면, 작업을 리뷰하기 위해 "code-review"로 Skill 도구를 호출하십시오.

작업을 현재 브랜치에 커밋하십시오.
