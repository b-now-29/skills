# Misc

보관은 하지만 거의 사용하지 않으며, 플러그인에서 승격되지 않은 도구입니다.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)**: 위험한 git 명령(push, reset --hard, clean 등)이 실행되기 전에 차단하도록 Claude Code 훅을 설정합니다.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)**: 테스트 파일을 `as` 타입 단언에서 @total-typescript/shoehorn으로 마이그레이션합니다.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)**: 섹션, 문제, 해답, 설명을 포함하는 연습 문제 디렉터리 구조를 생성합니다.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)**: lint-staged, Prettier, 타입 검사, 테스트를 포함하는 Husky pre-commit 훅을 설정합니다.
