# 명시적인 `/setup-matt-pocock-skills` 안내는 하드 의존성에 대해서만 둔다

엔지니어링 스킬은 `/setup-matt-pocock-skills`에 의해 초기 설정되는 저장소별 구성(이슈 트래커, 트리아지 라벨 어휘, 도메인 문서 레이아웃)에 의존합니다. 일부 스킬은 해당 구성 없이는 의미 있게 동작할 수 없습니다. 이러한 스킬은 특정 이슈 트래커에 게시하거나 특정 라벨 문자열을 적용해야 하기 때문입니다. 다른 스킬은 출력 품질을 높이는 용도(어휘, ADR 인식)로만 구성을 사용하며, 구성이 없더라도 점진적으로 성능이 저하될 뿐입니다.

우리는 이들을 **하드 의존성(hard-dependency)** 스킬과 **소프트 의존성(soft-dependency)** 스킬로 구분합니다.

- **하드 의존성** (`to-tickets`, `to-spec`, `triage`): 명시적인 한 줄 안내를 포함합니다. _"… 이(가) 제공되었어야 합니다. 그렇지 않다면 `/setup-matt-pocock-skills`를 실행하십시오."_ 매핑이 없으면 출력은 단순히 모호해지는 것이 아니라 잘못된 결과가 됩니다.
- **소프트 의존성** (`diagnose`, `tdd`, `improve-codebase-architecture`): "프로젝트의 도메인 용어집"과 "작업 중인 영역의 ADR"을 모호한 서술로만 참조합니다. 문서가 존재하지 않더라도 스킬은 여전히 동작하며, 출력의 정밀도가 다소 떨어질 뿐입니다.

이러한 구분을 통해 소프트 의존성 스킬의 토큰 사용량을 가볍게 유지할 수 있으며, 실질적인 역할을 하지 않는 곳에 설정 안내를 형식적으로 복제하는 일을 방지할 수 있습니다.
